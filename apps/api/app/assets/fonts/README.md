# Fonts

Latin Modern (GUST e-foundry, version 2.004), unmodified, from
https://www.gust.org.pl/projects/e-foundry/latin-modern. Licensed under the GUST Font License
(`GUST-FONT-LICENSE.txt`). Used to render tailored resumes as PDF: Latin Modern is the open
version of Computer Modern, the font of LaTeX resumes, and serves as the closest match otherwise.
